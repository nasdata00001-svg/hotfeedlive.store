🚀 도메인 연결 & 1시간 자동 호스팅 가이드

이 프로젝트는 Vercel (또는 Cloudflare Pages)과 GitHub Actions를 이용해 서버 비용 0원으로 1시간마다 전 플랫폼 실검을 크롤링하여 자동 배포할 수 있도록 설계되었습니다.

1. 도메인 구매

가비아, 호스팅KR, Cloudflare에서 원하는 도메인(예: trend-pulse.com)을 구매합니다. (연 1~2만원 내외)

2. 호스팅 배포 (Vercel)

GitHub에 이 코드를 올린 후 Vercel에 무료 연동하면 초고속 글로벌 CDN으로 배포됩니다. 구매한 도메인을 Vercel Settings에서 CNAME/A 레코드로 등록합니다.

3. 1시간 자동 발신 (GitHub Actions)

프로젝트에 포함된 .github/workflows/trend_cron.yml이 1시간마다 collector.py를 실행해 trends.json을 자동 갱신하고 push합니다.

4. 독립 서버 (VPS) 운영 시

AWS Lightsail(월 $3.5)이나 가상서버에 배포 시 내장된 server.py를 nohup 또는 systemd로 띄우면 내부 스케줄러가 1시간마다 자동 작동합니다.
